# Краткий обзор для YouTube

45 секунд, 1920 × 1080, 30 кадров/с, MP4 / H.264 / yuv420p, без аудиодорожки.
Русские субтитры встроены в кадр; `review.ru.srt` — отдельная дорожка для YouTube.
Название и описание подготовлены в `youtube-description.txt`.

Видео демонстрирует настоящие сцены через штатный `SceneCanvas`, а панели ящиков — через `ShortcutPocket.DrawToBitmap`. В ящиках используются специально созданные демонстрационные текстовые файлы. Это постановочный обзор из кадров приложения с увеличением деталей, а не запись всего рабочего стола. Личные настройки, пути и файлы не используются. Музыка из приложения в ролик не включена.

## Повторная сборка

На Windows с .NET Framework 4.8 и Python установите зависимости:

```powershell
python -m pip install --target .tools/python av numpy
powershell -ExecutionPolicy Bypass -File tools/video/BuildReview.ps1
```

Готовый проверенный ролик: `media/youtube/Kremlin-Lake-Wallpapers-Review-1080p.mp4`.
Контрольные кадры, журнал рендера, промежуточный MP4 и `verification.json` находятся в `.tools/video-output/`.
Сборка видео не меняет EXE приложения и установщик. Пользовательские обои не запускаются и не останавливаются.

Автоматическая проверка полностью декодирует видео, проверяет 1350 кадров, длительность, формат, время кадров, десять блоков субтитров и движение воды. Контрольные кадры необходимо также просмотреть визуально.
