# Кремль и озеро — интерактивные обои для Windows

Кабинет Кремля и отдых у озера: анимация воды, штора, лампа, монитор с часами или развевающимся флагом, ящики для файлов и выбор музыки в трее.

[Краткий видеообзор с русскими субтитрами — 45 секунд](https://github.com/MaksimDenisov31/kremlin-lake-wallpapers/releases/tag/video-review-2026-11-23). Подготовленные субтитры, описание для YouTube и инструкция сборки ролика находятся в [media/youtube](media/youtube).

## Скачать и запустить

### Обычная установка

1. [Скачайте KremlinLakeWallpapers-Setup-1.0.0.exe](https://github.com/MaksimDenisov31/kremlin-lake-wallpapers/releases/download/v1.0.0/KremlinLakeWallpapers-Setup-1.0.0.exe).
2. Запустите установщик, выберите папку и при желании создайте ярлык на рабочем столе.
3. Запускайте обои из меню «Пуск» или через созданный ярлык. В меню «Пуск» также есть команда остановки обоев.

Для передачи друзьям или на ноутбук достаточно **одного установочного EXE**: все изображения, анимации и музыка уже внутри. Установка выполняется для текущего пользователя, обычно без прав администратора, по умолчанию в `%LOCALAPPDATA%\Programs\Kremlin Lake Wallpapers`. Удаление — через **Параметры Windows → Приложения**. Обои при обновлении или удалении штатно закрываются.

Обновляйте установку в той же папке: настройки и содержимое ящиков сохраняются. При удалении программы **pocket-files**, адреса возврата и настройки остаются в прежней папке. Чтобы вернуть файлы из ящиков после удаления, установите обои снова в ту же папку. Личные данные из переносимой версии автоматически в новую папку установки не переносятся.

Требуются Windows 10 (1607+) / Windows 11 и .NET Framework 4.8 или новее. Установщик проверяет .NET и при его отсутствии предлагает официальную страницу Microsoft. Сам пакет .NET не включён; для его скачивания на старом компьютере потребуется интернет. После установки зависимостей обои работают без интернета. Цифровая подпись издателя не используется.

### Без установки

1. [Скачайте проект ZIP-архивом](https://github.com/MaksimDenisov31/kremlin-lake-wallpapers/archive/refs/heads/main.zip) и распакуйте его в отдельную папку.
2. Запустите **RussiaFlag.exe** или **Start.bat** — доступны оба способа. Сборка и интернет для запуска не нужны.
3. Настройки находятся в меню значка флага РФ в трее. **Stop.bat** закрывает обои на всех экранах и останавливает звук.

Повторный запуск не создаёт вторую копию обоев. Поддерживаются Windows 10 (1607+) и Windows 11.

## Мониторы и сцены

- При первом запуске используется обработанная ИИ-версия кабинета. В трее можно выбрать оригинальную фотографию.
- На одном мониторе можно выбрать кабинет или озеро. Меню интерактивных элементов показывает только элементы выбранной сцены.
- На двух мониторах отображаются обе сцены, их можно менять местами. Доступны интерактивные элементы обеих сцен.
- Общие команды паузы, подсказок и выключения звука доступны для любой сцены. Выбор сохраняется между запусками.

## Файлы в ящиках

Перетаскивание перемещает файлы в ящик. ПКМ → **Вернуть на прежнее место** возвращает выбранный файл обратно. Для защищённой папки Windows запросит права администратора; при отмене файл останется в ящике.

Содержимое ящиков находится в **pocket-files**, адреса возврата — в **pocket-office.txt** и **pocket-lake.txt**. При обновлении или переносе программы сохраняйте эти данные и **settings.ini**. Личные файлы и настройки исключены из Git.

## Инструкции и исходники

[Полная инструкция, музыка, управление и источники материалов](README.txt).

Исходники находятся в **src**. **Build.bat** собирает EXE штатным компилятором .NET Framework.

**BuildInstaller.bat** упаковывает готовый EXE и встроенные материалы с помощью Inno Setup 6/7. Результат — `installer-output\KremlinLakeWallpapers-Setup-1.0.0.exe`. При изменении исходников сначала выполните `Build.bat`, затем `BuildInstaller.bat`.

Сценарий установки — `installer/Wallpapers.iss`, проверка установки, обновления, удаления и сохранности ящиков — `tools/VerifyInstaller.ps1`. Тест использует отдельный AppId и собственные файлы, не останавливая текущие обои пользователя.
